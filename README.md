# Gulati Electric Co. — Indie Local Appliance Store Web App ⚡

An interactive, responsive single-page web application designed for **Gulati Electric Co.**, a trusted neighborhood electrical and home appliance retailer based in Block H, Kalkaji, New Delhi.

This project combines an **"Indie Local Retail Legacy"** aesthetic with modern web functionalities, including live product search, interactive appliance calculators, customer review submission, and seamless direct WhatsApp inquiry integration with store director Mr. Gaurav Gulati.

---

## 🌟 Key Features

* **Indie Neighborhood Aesthetics:** Custom-styled vintage indie storefront look using warm antique cream, deep crimson storefront red, and retro badge stamps.
* **Seamless Multi-View Router:** Client-side navigation across multiple views:
  * **Home:** Store highlights, brand marquee, and "Local Store vs Online Marketplaces" comparison table.
  * **Full Product Catalog:** Live search bar and filtering by category or brand (Sujata, Morphy Richards, Havells, Glen, Kenstar, etc.).
  * **Kitchen Chimneys & Stoves:** Dedicated showcase featuring an interactive **Chimney Suction & Size Calculator**.
  * **Air Conditioning & Cooling:** Dedicated showcase featuring an interactive **Room AC Tonnage Calculator**.
  * **Authorized Brand Partnerships:** Information on official brand warranties and GST invoices.
  * **Store Legacy & About:** Background history and personal director message.
  * **Customer Reviews:** Real Google review snapshots + interactive live review submission form.
  * **Contact & Location:** Google Maps integration, store timings, and direct contact form.
* **Interactive Inquiry Quote Drawer:** Allows users to build a quote list and send pre-formatted item inquiries directly to the store owner on **WhatsApp**.
* **Zero External Dependencies / Build Steps:** Pure HTML5, Tailwind CSS (via CDN), and Vanilla JavaScript. Runs directly in any web browser or hosted via **GitHub Pages**.

---

## 🛠️ Tech Stack

## 🚀 Quick Start & Deployment

### Running Locally
1. Clone this repository or download the source code:
   ```bash
   git clone https://github.com/your-username/gulati-electric-co.git
   ```
2. Navigate into the directory and open `index.html` in any modern web browser:
   ```bash
   cd gulati-electric-co
   open index.html   # On macOS
   start index.html  # On Windows
   ```

### Deploying to GitHub Pages
1. Push your repository to GitHub.
2. Go to **Settings** > **Pages** in your GitHub repository.
3. Under **Branch**, select `main` (or `master`) and `/root` as the folder.
4. Click **Save**. Your site will be live within seconds at `https://your-username.github.io/gulati-electric-co/`.
